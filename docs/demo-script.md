# สคริปต์สาธิต Chapanakit Care

ใช้ข้อมูลสาธิตที่ติดมากับโปรแกรม และเริ่มจากฐานข้อมูลใหม่เพื่อให้ลำดับการสาธิตทำซ้ำได้

1. เปิด `ChapanakitCare.Desktop.exe` แล้วเลือกนำเข้าข้อมูลสาธิต จากหน้า **ภาพรวม** แสดงจำนวนสมาชิกและการแจ้งเตือน
2. เปิด **ทะเบียนสมาชิก** สาธิตตัวกรอง, คลิกหัวตารางเพื่อเรียงน้อยไปมาก/มากไปน้อย, ลากหัวตารางเพื่อย้ายคอลัมน์ และใช้ **เลือกคอลัมน์**
3. เลือก **เพิ่มสมาชิก**: กรอกคำนำหน้าชื่อเพื่อให้เพศเติมอัตโนมัติ, เลือกกลุ่ม/ที่อยู่เพื่อให้ข้อมูลช่วยเติม, เว้นเบอร์โทรสมาชิกได้, และทดลองเลขบัตรผู้รับเงินสงเคราะห์ไม่ครบ 13 หลักเพื่อดูข้อความเตือนไทย
4. เปิด **ปรับสถานะสมาชิกลาออก**, ค้นหาสมาชิกสาธิต, ยืนยันการลาออก แล้วกลับไปทะเบียนสมาชิกเพื่อแสดงสถานะ **ลาออก**
5. เปิด **ทะเบียนผู้เสียชีวิต**: แสดงผู้รับเงินสงเคราะห์คอลัมน์ 1/2, สลับคอลัมน์, เรียง และลากย้ายหัวตาราง
6. เปิด **บันทึกการเสียชีวิต**: กรอกเลขสมาชิกเพื่อดึงข้อมูล, แนบ PDF ใบมรณะบัตร, ติ๊กกรณีไม่จ่ายเงินเพื่อดูยอดจ่ายเป็น 0; เอาติ๊กออกเพื่อดูค่าหัก 4% ที่ปัดลงเป็นบาทเต็ม แล้วบันทึกและกลับไปดูรายการในทะเบียนผู้เสียชีวิต
7. เปิด **รายงาน**: เลือกเดือน/ปีรูปแบบ `xx/xxxx` แล้วดาวน์โหลดรายงานสมาชิกประจำเดือนและ ส.ฌ.ก.๑; ดาวน์โหลด **รายงานสมาชิกทั้งหมด** และรายงานแยกกลุ่ม เพื่อตรวจหัวรายงานและข้อมูลตาราง

หมายเหตุ: รายงานสมาชิกประจำเดือนจะแสดงผู้รับเงินสงเคราะห์คนที่สองเป็นอีกหนึ่งบรรทัด โดยเว้นข้อมูลสมาชิกอื่นในบรรทัดต่อเนื่องไว้ตามรูปแบบรายงาน.
